# 🚀 Backend Developer

Este repositorio contiene los apuntes, ejercicios, proyectos y recursos de un curso **Backend**.


## 🛠️ Tecnologías y herramientas

Durante el curso se trabajará con:

- Node.js
- Express.js
- MongoDB (bases de datos NoSQL)
- SQL y bases de datos relacionales
- Git & GitHub
- Postman
- APIs REST
- Conexión a servidores y manejo de datos
